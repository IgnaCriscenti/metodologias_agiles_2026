# Ejercicio Nro: 5

## Enunciado
Proponga cinco elementos que ayuden en el desarrollo de software referido a la propiedad de flexibilidad que se requiere.

## Resolución
1. Patrones de Diseño: Utiliza soluciones probadas para problemas comunes, están diseñados específicamente para hacer que el código flexible ante nuevos requerimientos.
2. Testing: Contar con personal de pruebas permite realizar cambios, lo ideal es que el código sea lo suficientemente flexible como para modificarlo, y estos tests brindan seguridad ya que te ofrece calidad,
3. Interfaces: Cuando programamos orientado a interfaces y no a implementaciones concretas, permite por ejemplo cambiar una base de datos por otra sin modificar la lógica de negocio principal. Hay que saber aplicarlas, pero son muy útiles y te ahorran problemas.
4. Modularización: Dividie el sistema en partes pequeñas e independientes (módulos), y por ejemplo si necesito cambiar la lógica de una parte, no afecto al resto del sistema, lo que facilita enormemente el mantenimiento.
5. Bajo Acoplamiento y Alta Cohesión: Buscar que los componentes del software dependan lo menos posible entre sí (bajo acoplamiento) y que cada uno tenga una responsabilidad única y clara (alta cohesión). Esto evita el "efecto dominó" donde un cambio en un sitio rompe diez cosas en otro.
